# 周越英语学习法 · 口语：**learn in public**

**首先讲一下我的方法是怎么来的。**

练习口语，一定是要说的，这是肯定的。

**先找方法**

我个人的观点是：在盲目开始之前，先找到一个适合自己的、科学的、有神经科学验证的学习方法，这非常非常重要。我愿意在学习方法上花很多时间，然后不断打磨、不断试验，逐渐磨合出一版非常适合自己的方法。一旦方法对了，就能激活一个正反馈的循环——这个飞轮跑起来，之后的能力提升会非常快。

然后我找到了**尚雯婕**。因为我能从她的言行举止、她的思维里感觉到，她是一个聪明、理性的人，**我信任她**。

**她的方法是：找 20 分钟的新闻素材，先听写下来，然后一句一句地背，直到能把 20 分钟一口气流利地全部背出来。**这样的素材找 10 篇，就能攻克一门语言，口语表达得非常流利。

我相信她的方法。但她的方法有一个问题：20 分钟，这个门槛还是有点高。尤其对哑巴英语的人来说——虽然我自己的口语有点基础，但 20 分钟还是有门槛。

我想到了一个认知科学的研究：学习一件事的时候，难度每次提升 5%\~15%，一级一级地提，效果最好（出处在附录 A）。

然后我就想：**能不能把启动的门槛拉到无限低？**同时素材内容难度按 5%\~15% 提升。

**好，接下来找素材。**

其实这时候我已经做了一些前期准备：**把自己泡在英文环境里**——手机设成英文，平时刷 YouTube、X、Instagram 这些英文内容平台。这本来就是我刷手机的习惯，不费力。

并且我有注意到，Instagram 上有非常多类似播客、访谈或者电影台词的切片。它剪辑得非常好，有配乐，有感染力，有沉浸感。而且它讲的内容是很多是有营养的东西——人生哲理、给年轻人的建议、方法论、认知观、价值观。长度也是天然分好级的：一句话、几句话、一段话，十几秒到几分钟不等。最重要的是，这是真实情景里的口语表达，完全不是书面语，是真实生活中能用的。我就发现，这个素材非常好。

而且我平时刷社媒就有一个习惯：给刷到的内容收藏分类。看到一个内容，我会想它有价值吗？涉及什么领域？里面哪些是我能学习的？所以我有一个专门的收藏夹，专门收集这些切片，已经有几百条了。

接着我用 Claude Code 把这些素材全部扒下来：自动提取字幕和 caption，按内容长度、主题分类，按难度从简到难——从一句话到两句话到一段话——整理进我个人的 Obsidian 库里。

**最后一块拼图是 勇气 :  learn in public：**

通过输出倒逼输入。自己拍摄，模仿里面的人物，然后分享到自媒体平台。

这个方法解决了一个非常好的问题：你自己背，和真人面对面说，压力是不一样的——自己跟自己背，**缺少真实环境的压力。**但这个口播的内容是要发出来的，你想象中要面对非常多的人——真实场景的压力模拟也解决了。

同时，难度门槛极低，解决了；难度逐级提升，解决了；而且素材的内容不是枯燥无用的信息，是真的能帮到自己的哲理——学这个内容本身就有意义，模仿本身就带成就感，很快乐。分享出去之后，有人留言、鼓励、点赞，**这就是正反馈的飞轮，循环就转起来了。**

## 附录 A：方法与认知科学背景

**费曼学习法** —— 物理学家理查德·费曼（Richard Feynman）的学习思想：能用自己的话讲出来，才算真正理解。检验学习的唯一标准是输出。

**尚雯婕外语学习法** —— 找 20 分钟新闻素材 → 全文听写 → 逐句背诵 → 流利背出整段，做 10 篇攻克一门语言。内核（听写 + 背诵）保留在本系统中作为基本功；起步剂量按 85% Rule 改造为 0 启动。

**85% Rule** —— Robert C. Wilson、Amitai Shenhav、Mark Straccia、Jonathan D. Cohen（亚利桑那大学、布朗大学、UCLA、普林斯顿），2019 年发表于 *Nature Communications*（doi:10.1038/s41467-019-12552-4）。对一大类基于梯度下降的学习算法，训练准确率保持在约 85%（错误率约 15.87%）时学习速度最快。太简单（100% 正确）没有新东西可学，太难（大面积错误）同样学不动。本系统的难度阶梯即以此为依据：每级素材保持"大部分能跟上、偶尔会卡住"。

**语音回路（Phonological Loop）** —— Baddeley 工作记忆模型中负责暂存和复述声音信息的子系统。重复模仿 10-20 遍，练到做饭、走路时耳朵里自动响起那个声音，说明表达已进工作记忆的自动化通道。没有回路 = 只是看过，没进脑子。

**什么叫听懂** —— 听懂 = 语言背后的概念场景和脑子里的东西匹配上了。一个词在你脑中有印象、有画面（一团神经元），耳朵听到声音、眼睛看到符号时二者匹配，即为听懂。同一个词在不同场景中反复出现 = 概念与不同上下文的交织，场景越多连接越密。这与大模型词向量的形成同理：一个词在海量上下文中反复共现，表征被反复校准——多样化的场景就是多样化的训练样本。

**提取练习与睡眠固化** —— 记忆在提取时被强化，所以说出来才有用；海马体在睡眠中把短期记忆固化到皮层，一次睡眠 = 一次循环，练完不睡等于白练。每天 1-2 次、每次 1 小时以内，神经元生长需要休息。

**情感与记忆** —— 带情感的记忆更容易被巩固，所以收藏素材的触发器是"我喜欢"，不是"这个有用"。

**Learn in Public** —— 开发者社区提出的公开学习理念（Shawn Wang / swyx 的《Learn in Public》一文是代表作）：不等学成再展示，把学习过程本身公开发布。它同时提供真实的外部压力和持续的正反馈。

## 番外篇

### 番外一：我观察到的小孩是怎么学话的

小孩学话，憋得很难受却说不出来的那一刻——妈妈猜到了、引导了、反馈了，**嘣，神经元连上了。**

小孩有个天性：特别在意 attention。他会观察自己看的东西和大人看的是不是同一个。两个人的注意力对上了，他就咿咿呀呀，大人顺着引导——比如两个人同时在看一个苹果，妈妈指着说 "apple"，他就记住了。他也很关注自己有没有被关注。

语言习得的底层机制就是这样：两个想连在一起的神经元，只在"想表达却表达不出来"的那个瞬间被触发；这个瞬间往往发生在注意力对上的时候；外部反馈在那个瞬间到来，连接就形成了。

**AI 是历史上第一个可以随时随地扮演"懂你的妈妈"的工具。** 你说什么它就接什么，它的注意力永远在你正关注的东西上，24 小时都在。

### 番外二：什么是声音回路

你刷短视频的时候，有没有过某首歌的旋律突然在耳朵里自动响起？那就是声音回路被激活了。

语言学习里，这个回路叫 Phonological Loop（语音回路），是工作记忆的一部分。建立方法：找到你喜欢的表达者的切片，**重复模仿 10-20 遍，直接模仿音调和节奏，不翻译**，直到你做饭、走路的时候，耳朵里会自动响起那个声音。

**声音回路建立了 = 学进去了。没有回路 = 只是看了，没进脑子。**

### 番外三：我的发现——输出之后，听力和阅读也变好了

我自己练下来发现一个现象：在输出的时候，我的听力变好了，同时我的阅读也变好了。

我看过 MiniMax 闫俊杰的分享：MiniMax 做多模态的时候，一个领域的模型训练好之后，另一个领域会自然变好——好像一个模态训好了，语音模型也跟着好了。

人的语言系统可能也是同一个道理：**听、说、读、写不是四个独立的模块，底层是同一套表征。** 一个练上去了，其他的跟着受益。

### 番外四：阅读是另一套方法

阅读我用的是「五级骨架递进法」——骨架留英文、生词换中文，S1 → S2 → S3 → 原文，逐级递进。

口语和阅读共享同一条根本原则：**大脑不能同时跑多个进程。拆开跑，各自自动化，自然合并。** 详见《周越英语学习法 · 阅读》。
